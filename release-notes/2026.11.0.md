The first release of Graphink, the successor to GraphSketcher: a modern Mac app for drawing graphs by hand, with its own document format, a guided welcome and ready-made examples, data charts and templates.

### Added

- A Welcome to Graphink guide that opens on first launch and from Help > Getting Started. Every part of it is a real graph you can edit to try each tool.
- File > New From, with 18 annotated microeconomics lessons, from market equilibrium and tax incidence to monopsony, Cournot duopoly and externalities, three charts built from official Spanish data (income tax concentration, tax revenue as a share of GDP, house prices and wages in real terms) and nine templates: function plot, time series, scatter plot, bar chart, logarithmic scale, number line, supply and demand, Lorenz curve and production possibilities frontier. Each opens as a new, untitled copy.
- Credits on every example and data chart, with the sources of the concepts and of the official data.
- Paper sizes for the canvas: choose A4, A5 or US Letter in portrait or landscape from the Canvas inspector, or keep a custom size. Sizes are shown in points, millimetres and inches.
- A resolution choice when exporting PNG, JPEG or TIFF (72, 144, 150 or 300 DPI), with the exact pixel size shown before you export. The exported image has that size on any display.
- Zoom for the canvas: 25%, 50%, 100%, 200%, 400% or Fit, from the menu at the bottom-right of each window. Zooming and resizing the window never change your graph, and snapping works at the same on-screen distance at every zoom.
- Style presets (Paper, Sketch, Chalkboard, Studio and Editorial) from Arrange > Apply Style Preset. Editorial gives a news-chart look: horizontal grid lines only, a baseline under the data, no vertical axis line or tick marks, and a strong blue for new lines.
- Edit > Find: search the text of labels, axis titles, point labels and typed tick labels with the find bar (Command-F), then step through the matches with Find Next (Command-G) and Find Previous (Shift-Command-G). Each match is selected and scrolled into view without changing the graph.
- A new document format, .graphink, that Graphink opens and saves by default. Older .ograph files still open, and Save keeps them as they are.
- Help > Release Notes shows what changed in each version. After an update with new notes, they also appear once on their own.

### Fixed

- Changing the width of a selected line or point no longer changes the default width of new lines.
- Arrowheads in the middle of a multi-segment arrow in older GraphSketcher files now point the right way, and keep doing so after saving and copying.
- The Licenses and acknowledgments link in About Graphink opens in your web browser.
- After a crash, a new document that was never saved comes back with its contents. Changes are now autosaved within seconds instead of after two minutes.

### Improved

- Finder shows .graphink files as Graphink Documents and opens them with Graphink. .ograph files are listed as GraphSketcher Documents.
- The window transparency button is now part of the default toolbar.
- When you save a copy of an .ograph file as a Graphink document, the Save panel shows the .graphink extension.
- New keyboard shortcuts so that Find works as in other Mac apps: Arrange > Group is now Option-Command-G, View > Show Grid is Command-' and View > Snap to Grid is Shift-Command-'.

### Command line

- A `graphink` command-line tool, inside the app: `graphink render` exports any .graphink or .ograph document to PDF, PNG, JPEG or TIFF exactly as File > Export does, and `graphink create` builds an editable document from a short JSON description. Choose Graphink > Install Command-Line Tool… to see the Terminal command that puts it on your PATH. The release also offers it on its own as graphink-cli.zip.
- `graphink create` can add a best-fit line to a data series: Graphink's own least-squares line, labelled with its equation and R², which moves with the points when you drag them in the app.

### Agent skill

- An agent skill that teaches Claude Code and other coding agents to make Graphink documents with the `graphink` tool, check the rendered image and hand over the editable file. Install it with `npx skills add diegomarino/graphink`.
